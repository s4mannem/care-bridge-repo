# `tests` — Certification & Unit Test Suite

The [`tests/`](file:///Users/dvt112/Downloads/A4I/tests) directory contains the unit and end-to-end certification suites for CareBridge Fulton's contracts, security guardrails, BigQuery MCP data plane, spatial optimizer tool, and ADK agents. Every test file is self-contained, deterministic, and runs offline using the Fulton County (`13121`) fixtures and stub/mock BigQuery MCP bridges.

---

## Running the Test Suite

Run all certification tests via Python's built-in `unittest` discovery:

```bash
python3 -m unittest discover -s tests -p "test_*.py" -v
```
